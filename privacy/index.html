PRIVACY

Browser-first by design.

The candle, Halloween candy, and Christmas lights calculations run locally in your browser. If you choose to save an actual Halloween turnout count, it is stored in that browser's local storage. The pumpkin stencil maker processes the selected image in the browser, and the PDF binding-margin tool reads and transforms the selected PDF in the browser; this code does not upload those files to a Quicklio server.

Update this page before enabling analytics, advertising, or server-backed features that change those facts.
