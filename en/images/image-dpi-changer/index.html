Convert an image to 300 DPI

Set the target to 300 DPI and choose whether you only need physical-density metadata or actually need enough pixels for a specified print size.

DPI metadata is not extra detail

Changing DPI metadata alone does not create new image detail. It changes the relationship between pixels and physical print size.

Resample when print dimensions matter

If a printer needs a six-inch image at 300 DPI, resample mode creates an 1800-pixel-wide output and writes the matching DPI metadata.

Frequently asked questions

Does changing DPI improve image quality?

Not by itself. Metadata-only mode leaves every pixel unchanged. Resampling can add or remove pixels, but it cannot invent missing photographic detail.

What does 300 DPI mean?

At 300 DPI, 300 image pixels map to one inch of physical print width when the software respects the density metadata.

Which formats are supported?

This tool supports PNG and JPEG because both have widely used physical-density metadata that can be updated reliably in-browser.
