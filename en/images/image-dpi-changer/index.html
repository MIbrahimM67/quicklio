Convert an image for 300 DPI printing

Choose a target DPI and physical print width to calculate and create the pixel dimensions required for that print. In resample mode, Quicklio resizes the image to those dimensions in your browser.

Changing DPI does not magically add detail

An image with too few source pixels cannot gain real photographic detail simply by changing a DPI number. Resampling can create the correct pixel dimensions for a workflow, but print sharpness still depends on the quality of the source image.

Keep pixels versus resampling

Use keep-pixels mode to preserve the current pixel dimensions while writing physical-density metadata into the downloaded PNG. Use resampling when a print workflow requires a specific pixel dimension at a chosen physical width.
