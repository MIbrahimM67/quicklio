Turn a photo into a cross-stitch pattern

Quicklio downsamples your image to a stitch grid, matches the result to a built-in DMC reference palette, limits the number of colors, and counts how many stitches use each selected thread color.

Choose pattern width before choosing colors

The stitch width controls detail. A very wide grid can preserve facial features and texture but creates more individual stitches. A narrower grid simplifies the design and is usually easier to stitch.

Thread list export

Download the chart preview as PNG and the selected DMC thread list as CSV. The stitch counts are useful for comparing colors, but always allow extra floss for starts, stops, carrying, mistakes, and your preferred stitching technique.

Color note: screen colors and physical floss can differ. Use the generated DMC mapping as a planning aid and compare against real floss when color accuracy is critical.
