Create a tattoo stencil from a photo or drawing

This tool turns high-contrast artwork, sketches, and reference images into clean black stencil output. Adjust line threshold, contrast, noise cleanup, smoothing, physical size, and optional mirroring before exporting.

Mirror mode for transfer workflows

Some transfer workflows need mirrored artwork while others do not. Use the mirror switch only when your transfer method requires it, and verify orientation before applying a stencil to skin.

Best source images

Clean drawings with strong edges produce the most predictable result. Photographs may need more threshold and cleanup adjustment because shading contains many intermediate tones.
