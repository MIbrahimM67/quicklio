What are PDF page boxes?

A PDF page can carry five rectangles. MediaBox is the physical page boundary. CropBox controls normal viewing/printing clipping. BleedBox describes the production bleed region. TrimBox describes the intended finished page after trimming. ArtBox describes the meaningful artwork area.

CropBox defaults to MediaBox when it is absent. BleedBox, TrimBox, and ArtBox default to CropBox. Quicklio labels those fallback values as “default / inherited” so you can distinguish them from explicitly stored box entries.

When should you edit TrimBox or BleedBox?

Use this when a printer, prepress check, imposition workflow, or publishing platform expects explicit trim or bleed metadata that your PDF does not contain. A common workflow is to set the finished page as TrimBox and then place BleedBox a few millimeters outside it.

Do not use page-box metadata to fake missing bleed. If artwork stops at the trim edge, setting a larger BleedBox does not create new artwork beyond that edge. For artwork preparation, use Add Bleed & Crop Marks.

Page boxes vs cropping a PDF

Changing CropBox can change what is visible without rebuilding the page content. Quicklio’s Crop PDF tool is better when your actual goal is trimming visible margins into a newly sized output page. This editor is for precise PDF box metadata and prepress geometry.

Safety checks built into the editor

  • All edited boxes must have positive width and height.
  • CropBox, BleedBox, TrimBox, and ArtBox are checked against MediaBox.
  • Quicklio warns when TrimBox is not contained by BleedBox.
  • The exported PDF is reopened and the changed values are verified before download.
