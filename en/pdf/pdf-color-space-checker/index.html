      Print metadata

        This is a diagnostic checker, not a color conversion or press-ready certification. PDFs can mix color spaces object by object, and some profiles or image color information may be encoded in ways a lightweight browser scan cannot identify exhaustively. Follow the requirements of the printer or publishing service that will actually output the file.

        Is my PDF RGB or CMYK?

        A PDF does not have to use one global color mode. Text, vector artwork, images, gradients, and spot inks can use different color spaces in the same file. That is why this checker reports the signals it finds instead of forcing the entire PDF into a single label.

        If both RGB and CMYK are detected, the result says Mixed RGB + CMYK signals. That is useful evidence, but it is not automatically an error: the correct requirement depends on the print workflow.

        What Quicklio checks

        • Page drawing operations that directly paint in RGB, CMYK, or grayscale.
        • Readable PDF declarations such as DeviceRGB, DeviceCMYK, DeviceGray, ICCBased, Lab, Indexed, Separation, and DeviceN.
        • Named Separation and DeviceN inks when their names are exposed in the PDF structure.
        • Basic PDF/X and output-intent signals where they can be identified.

        What this tool does not do

        It does not convert RGB artwork to CMYK, assign ICC profiles, simulate a press, calculate ink coverage, or guarantee that a file satisfies a printer's complete preflight specification. A correct CMYK conversion needs a target output condition, not a generic one-click replacement.

        For geometry problems, use the PDF Page Box Editor to inspect TrimBox, BleedBox, CropBox, MediaBox, and ArtBox.

        PDF color checker FAQ

        Can one PDF contain both RGB and CMYK?

        Yes. Different objects inside a PDF can use different color spaces, so mixed files are possible.

        Does finding RGB mean the PDF will print badly?

        No. It means RGB signals were found. Whether they are acceptable depends on the printer, RIP, output profile, and production requirements.

        Does this convert a PDF to CMYK?

        No. It is intentionally a checker. It does not rewrite colors or silently change profiles.

        Private browser-only analysis

        Your PDF is read by JavaScript running in your browser. Quicklio does not need to upload the document to a conversion server for this check. Large or unusually complex PDFs can still take longer because every page's drawing operations need to be inspected on your device.

        What are spot colors?

        PDF spot colors are commonly represented by named Separation or DeviceN color spaces. This checker surfaces those names when they are exposed in readable PDF structure.
